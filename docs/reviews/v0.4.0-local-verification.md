键盘交互及跨尺寸检查；最后按 unslop 检查全部页面，保留工具型应用的密度，

## 数据和安全边界

- 全量导出先认证、再选择账号独立库，在工作线程内采用单次 SQLite 读事务，
  记录、格式 blob 与智能列表属于同一快照。测试覆盖超过一页的 105 条记录、
  未登录、其他账号隔离和关闭服务器存储。
- 多选删除仍是逐条普通因果 tombstone，不声称跨记录原子提交；每条沿用
  版本向量、冲突保留和事务 outbox。中途失败停止并报告已处理数量，后续成功
  不会覆盖失败。Web 保留未处理选择，并隔离切换账号后的迟到响应。
- PNG 缩略图只存在于 UI 快照缓存，不写回数据库。限制输入字节数、尺寸、
  解码内存、缓存容量和每轮工作量；复制/粘贴从已保存记录加载完整 payload。
- 清理和同步协议不变，仍遵守既有因果/冲突恢复设计；不改为简单时间戳覆盖。
- 保留 NSH Updater、默认关闭和包管理器/未知来源禁用规则，不放宽更新信任边界。

## 验证证据

- Rust workspace 120 项测试；Web 13 项 Node 测试。
- `cargo fmt --all --check`、`cargo clippy --locked --workspace --all-targets -- -D warnings`、
  Linux client/server release 构建与 Linux 便携归档内容检查。
- 新回归覆盖默认阅读/放弃草稿、队列移除/撤销、设置输入框/开关窄宽布局、
  PNG 缩略图不污染完整复制、伪语言与旧键移除、账号隔离全量导出，以及 Web
  三态外观、相对日期、批量部分失败及导出入口。
- 真实 Linux X11 原生窗口与浏览器使用隔离演示数据库；README 图片为实际
  渲染结果，不是 HTML 仿制图。检查历史/详情、队列、设备、预览、设置、
  Web 历史/详情/设备/账号/连接弹窗，中英、浅深色及 390px 窄屏。
- 视觉回归发现设置过滤 class 将卡片重置为横排，修复为显式纵排并约束宽度；
  失败后通过的布局回归覆盖两种宽度。成功 toast 不再拦截底下的保存按钮点击。
- 原生类型筛选使用 radio 的 checked 状态，避免已验证的 Button selected
  在页面销毁时触发 NSH disposed-owner 访问；测试日志检查无该类 caught panic。

保留的 manifest 提示：workspace 的 `arboard` 与客户端的 `directories` 为
既有未使用依赖警告，不将其描述为零警告构建。
本机缺少 `dpkg-shlibdeps`，完整 Linux 包装命令在生成便携归档后停止；deb 的
依赖解析、打包和校验交由 Ubuntu 发布流水线完成，不把本地这一步记为通过。

## 未实现及平台限制

- 本版未加入设备码二维码或真实浮窗透明度；固定 NSH 窗口接口未提供后者，
  不以淡化内容冒充窗口透明。设备页不显示没有可靠数据来源的“在线/上次同步”。
- 设置搜索按分组及已列入的字段标签匹配，不是任意帮助文字的全文搜索。
- 伪语言只供开发测试，不作为正式支持语言；大字体、RTL 和屏幕阅读器未做
  完整人工验收。
- Windows/macOS 的 GUI、Android 真机、真实登录启动和跨版本自替换未在本机
  复验；不能以跨平台编译通过替代这些验证。桌面未签名、macOS 未公证，
  Android 继续是 CI 测试签名 APK。
