# Issue #1 在 0.2.1 中的适用范围

来源：https://github.com/ca-x/yank/issues/1 。该 issue 在 Makepad 客户端时期制定；后续用户已经选择 NSH、重写服务端及自有同步，因此其中保留 Makepad 和冻结服务端的方案不再适用。

本次采用其最直接改善日常使用的交互建议：

- 历史列表以键盘为优先，搜索框获得焦点后可输入、用上下键选择、回车粘贴；前十条显示序号，可用 Ctrl/⌘+1…0 快贴。
- 选择记录和打开详情分开；窄窗口中的上下键不会跳到详情。详情中单独提供“粘贴到原应用”，全局设置仍从原有导航和托盘进入。
- Esc 在子页返回历史，在历史页隐藏窗口，继续后台记录。
- 空历史与搜索或筛选无结果有不同说明；侧栏列表可滚动，底部设置入口固定可见。
- 沿用现有语义主题、共享控件、收藏状态和浅深色外观，不引入未实现功能的占位菜单。

粘贴仍受系统输入权限约束：先隐藏 Yank，再等待外部应用恢复焦点，随后发送粘贴键；Wayland 无法确认全局输入授权时只写入剪贴板并要求手动粘贴。粘贴从数据库读取完整记录，不依赖列表摘要或异步详情响应；搜索尚未返回时不贴旧结果。

本次不宣称已完成 issue 中所有 Ditto 能力：多选、单条快捷键/别名、独立紧凑弹窗、无焦点自动隐藏、全部搜索模式、透明度和菜单分组仍属后续工作。本版仍使用历史主窗口，未把它描述成独立快速粘贴窗口。

- 独立 UI/UX agent 完成 Logo 和快速粘贴复审，审核提出的 Enter 按钮冲突、已删除记录粘贴和详情依赖列表问题均已修正，最终确认无阻塞。
