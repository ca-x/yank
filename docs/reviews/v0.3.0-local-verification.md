# 0.3.0 本地验收

日期：2026-11-13。基线：公开版本 v0.2.1（caaa7ed）。

## 数据与同步

- Rust workspace：113 项测试通过，包括清理回滚、跨连接收藏竞态、两客户端与服务端乱序/重复/并发删除编辑，以及显式冲突恢复。
- 最近历史覆盖偏好升级、逻辑使用排序、同步日志不变、复合游标多页、窗口 sentinel、日期范围和旧数据库迁移。多页窗口在单次 SQLite 读快照内读取。
- 实际 EXPLAIN QUERY PLAN 确认 seek 使用 clips_history 的 `(deleted,(pinned,recency,id))`，不使用临时排序树。子串搜索、日期/收藏板过滤仍可能扫描较多索引项；不声称所有查询都是恒定时间。
- 升级新增数据库列，降级须恢复旧备份；清理只是逻辑删除，不声称数据库文件缩小。见清理一致性设计。

## 更新与打包

- 桌面使用固定 NSH revision 的 nsh-updater（Rust 对应 nsh/updater），移除 self_update；HTTP 由 reqwest 提供。
- 默认不检查；手动入口及每日任务均受安装来源约束。仅带正确便携标记的程序目录可更新；系统路径、软件包文件归属、Homebrew/Scoop/WinGet/Flatpak 等管理痕迹被拒绝，未知安装失败关闭。
- Windows 注册表发现 Yank 的卸载注册信息时保守地禁用自更新，包括可能同时存在的便携副本；避免自定义包管理器安装路径绕过限制。标记不是防恶意篡改的安全凭证。
- 更新清单与下载均限制为 HTTPS；限制大小，验证 SHA256 和完整长度后才安装。一次只执行一项更新，不强制重启；新版本下次启动生效。
- 更新单测覆盖系统/管理器路径、缺失或错误标记、Scoop 元数据、其他应用清单及损坏下载。发布清单生成验证五个平台、hash/大小及缺少归档时拒绝生成。
- 发布流水线在汇总全部平台后生成 latest.json，指向版本固定的归档；GitHub 清单未配置独立 Ed25519 签名，不宣称发布签名验证。
- Linux release 构建及隔离便携目录真实启动通过。未在测试中对真实安装执行在线自替换，也未开启真实开机启动项。

## 平台边界

本地环境是 Linux X11 远程桌面，出现 portal/AT-SPI/输入法模块警告，全局热键授权不可用；截图如实保留提示。Windows/macOS GUI、Android 真机、各平台真实登录启动和包管理器现场升级未实机验收，不能用跨平台 CI 构建替代。桌面仍未签名，macOS 未公证；Android 仍是测试签名。
